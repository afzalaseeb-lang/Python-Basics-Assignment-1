# Python-Basics-Assignment-1
Python basics assignment covering string concatenation, string slicing and indexing, string methods, and tuple operations using Google Colab.

## Overview
This repository contains Python programming exercises completed using **Google Colab**. The assignment focuses on fundamental Python concepts, including string manipulation and tuple operations.

## Topics Covered

1. **String Concatenation** – Combining strings and accepting user input.
2. **String Slicing and Indexing** – Accessing individual characters, extracting substrings, reversing strings, and extracting specific words.
3. **String Methods** – Using `upper()`, `lower()`, `capitalize()`, `count()`, and `replace()`.
4. **Tuple Operations** – Creating and concatenating tuples, repeating elements, and accessing elements using indexing and slicing.

## Tools Used
- Python
- Google Colab

## How to Run
1. Download or open the `.ipynb` notebook file.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook or open it from Google Drive.
4. Run each code cell to view the output.

## Learning Outcomes
- Understand basic Python syntax and operations.
- Perform string manipulation using built-in methods.
- Apply indexing and slicing to strings and tuples.
- Understand tuple concatenation and repetition.
